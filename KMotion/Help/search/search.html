Search the Help manuals, the Wiki, the Forum and the Store in one place.

Search syntax
encoder noisepages containing both words (implicit AND)
"closed loop step"exact phrase
kflop OR kognaeither word
spindle -mach3exclude a word (also NOT mach3)
servo (kanalog OR snapamp)grouping with parentheses
setbit*prefix wildcard: SetBit, SetBitDirection, …

Searching for a product name (e.g. kflop) shows its Store purchase page first, unless Store is un-checked. Words match exactly (no stemming), so axis does not match axes — use ax* or axis OR axes. Matching is case-insensitive. Version numbers, decimals and IP addresses are single terms: 5.4.4 matches only the literal 5.4.4. Results are ranked by relevance (BM25): rare words count more than common ones, matches in page titles count extra, and shorter pages rank above long ones with the same number of matches.
